Antes de começar

O que é isso e por que instalar

O Google Tag Manager (GTM) é o "hub" que centraliza todo o rastreamento do site — Google Ads, Meta Ads, GA4, eventos de conversão. Sem ele instalado, a gente fica cego em relação ao que acontece no site depois que alguém clica num anúncio.

O container já foi criado do lado da Brito Mídias. Falta só colar dois trechos de código no site, uma vez, em todas as páginas.

ID do container: GTM-MCQ7N3L2

Esse ID é único do CEVEPE. Se o código-fonte do site já tiver outro ID de GTM instalado, não sobrescreva — chama a Brito Mídias antes pra decidir se substitui ou mantém os dois.

O código

Copie e cole os dois trechos

São os mesmos dois códigos que aparecem na tela de instalação do Google Tag Manager. Não precisa alterar nada — só copiar exatamente como está.

1
Cole isto o mais alto possível dentro do <head> da página Antes de qualquer outro <script>, logo após o <meta charset> e o <title>
Código do <head> 
<!-- Google Tag Manager -->
<script>(function(w,d,s,l,i){w[l]=w[l]||[];w[l].push({'gtm.start':
new Date().getTime(),event:'gtm.js'});var f=d.getElementsByTagName(s)[0],
j=d.createElement(s),dl=l!='dataLayer'?'&l='+l:'';j.async=true;j.src=
'https://www.googletagmanager.com/gtm.js?id='+i+dl;f.parentNode.insertBefore(j,f);
})(window,document,'script','dataLayer','GTM-MCQ7N3L2');</script>
<!-- End Google Tag Manager -->
2
Cole isto imediatamente após a tag de abertura <body> Como primeiro elemento dentro do body, antes de qualquer conteúdo visível
Código do <body> (noscript) 
<!-- Google Tag Manager (noscript) -->
<noscript><iframe src="https://www.googletagmanager.com/ns.html?id=GTM-MCQ7N3L2"
height="0" width="0" style="display:none;visibility:hidden"></iframe></noscript>
<!-- End Google Tag Manager (noscript) -->

Instale os dois. Só o código do <head> não é suficiente — o do <body> garante o rastreamento de quem acessa com JavaScript desabilitado. E lembre de colar em todas as páginas do site (ou só no arquivo de layout/template, se o site usar um).

Mensagem para a IA 
Preciso instalar o Google Tag Manager (ID GTM-MCQ7N3L2) neste site. Cole o snippet 1 o mais alto possível dentro do <head>, antes de qualquer outro script. Cole o snippet 2 imediatamente após a abertura do <body>, antes de qualquer conteúdo. Aplique em todas as páginas do site (ou no arquivo de layout/template compartilhado, se existir). Não modifique o código dos snippets, não troque o ID, e não duplique se o GTM já estiver instalado.

SNIPPET 1 (head):

A IA vai identificar o framework do site (Next.js, Astro, WordPress, etc.) e colar os snippets no lugar certo automaticamente.

Depois de instalar

Como confirmar que funcionou

Só funciona depois de publicar o site (não vale rodar local). Qualquer uma das 3 formas abaixo confirma:

  • Tag Assistant: acesse tagassistant.google.com → "Add domain" → cole a URL do site → deve aparecer GTM-MCQ7N3L2 como "Connected"
  • DevTools do navegador: abra o site → F12 → aba Console → digite dataLayer e aperte Enter. Se retornar um array (mesmo vazio []), funcionou. Se retornar undefined, não instalou
  • Preview do GTM: no painel do Google Tag Manager, clique em "Preview" e cole a URL do site — deve conectar

Qualquer dúvida ou se algo não bater, chama a gente no WhatsApp que a Brito Mídias ajuda a validar junto.
